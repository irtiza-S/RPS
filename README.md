# Rock Paper Scissors

A browser-based Rock Paper Scissors game built with HTML, CSS and vanilla JavaScript. Play against the computer, first to 5 wins.
https://irtiza-s.github.io/RPS/

## Features

- Click rock, paper or scissors to play a round
- Computer picks its move at random
- Live scoreboard for player and computer
- Message after each round showing who won it
- Game ends when either side reaches 5 points
- Reset button to start a new game

## How to Play

1. Choose rock, paper or scissors.
2. The computer makes its choice and the round winner gets a point.
3. First to 5 points wins the game.
4. Press **Reset** to play again.

## Rules

- Rock beats scissors
- Scissors beats paper
- Paper beats rock
- Matching choices are a draw and nobody scores
